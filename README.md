# khistory_cram_pwa

고1 한국사 시험직전 취약점 강화 PWA 웹앱입니다.

## 패드 적용 순서
1. 이 ZIP 파일을 PC에서 압축 해제합니다.
2. 압축 해제한 폴더 안의 index.html, manifest.webmanifest, sw.js, icons 폴더를 웹호스팅 또는 학교/기관 웹서버에 업로드합니다.
3. iPad는 Safari, 갤럭시탭은 Chrome에서 업로드된 index.html 주소로 접속합니다.
4. 공유 버튼 또는 브라우저 메뉴에서 홈 화면에 추가를 선택합니다.

## 파일 구성
- index.html: 웹앱 본체
- manifest.webmanifest: PWA 설치 설정
- sw.js: 오프라인 캐시용 서비스워커
- icons/: 홈 화면 아이콘
- study_notes.md: 핵심정리 원본 참고 파일

## 주의
학습 기록은 각 기기의 브라우저 저장소에 보관됩니다. 같은 기기, 같은 브라우저, 같은 주소로 접속하세요.
